# 経営ロード

経営の流れ（企画 → 仕入れ → つくる → 売る → 回収）を一周する盤で、4社が5年後の資産を競う3Dのボードゲームです。
サイコロで進むと、進んだマスの数だけ売上が入ります。止まったマスでは、中小企業の経営で起きそうな出来事や2択が起きます。
出来事の多くは中小企業診断士の試験で扱う考え方に沿っていて、出会った言葉は「本の言葉ノート」に残ります。

**遊ぶ:** https://admiral-kid.github.io/keiei-road/

- 1年は8ターン。年末に決算して、費用と税金を払う。5年後に資産がいちばん多い会社の勝ち
- 開業のときに、会社の種類と、銀行からいくら借りるかを選ぶ
- 商品を開発し、設備・宣伝・人材・研究開発に投資して、1マスの売上を伸ばす
- 分かれ道は4つ。道を抜けると、選んだ道ごとの効果が起きる
- 5年後、出会った本の言葉から5問の「経営者レベル判定」があり、正解の数で資産が増減してから最終順位が決まる

進み具合（本の言葉ノート、戦績、音と速さの設定）はブラウザの LocalStorage に残ります。このリポジトリには、ビルドした `index.html` だけを置いています。
